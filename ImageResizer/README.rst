Image Resizer
=============

A desktop app for resizing, converting and compressing many images at once.
Built with `Toga`_ and `Pillow`_, packaged with `Briefcase`_.

Features
--------

- Add single images, whole folders, or drag and drop from Explorer (Windows)
- Resize modes: **Fit within**, **Fill and crop**, **Exact size** (with aspect lock), **Percentage**
- Academic presets (presentation slides, thesis figures, posters, Moodle, ID photos) plus web and social media
- File size limit for upload systems (quality first, then resolution)
- Convert to JPEG, PNG, WebP, BMP, GIF or TIFF, with a quality slider for JPEG and WebP
- Keeps or strips EXIF metadata, always removes GPS location unless you allow it, fixes photo rotation
- Live preview of the result, including crops
- Safe output naming (``photo_resized.jpg``, ``photo_resized (2).jpg``…)
- English and Polish interface, switchable at any time
- Remembers your settings

Running from source
-------------------

.. code-block:: console

    python -m venv .venv
    .venv\Scripts\activate
    pip install toga pillow pytest
    cd ImageResizer
    set PYTHONPATH=src
    python -m ImageResizer

Tests
-----

.. code-block:: console

    cd ImageResizer
    set PYTHONPATH=src
    python -m pytest tests

Building an installer
---------------------

.. code-block:: console

    pip install briefcase
    cd ImageResizer
    python tools/build_windows.py

This creates in ``dist/``:

- ``ImageResizer-<version>.msi``: installer with a Polish setup wizard
- ``ImageResizer-<version>.zip``: portable version (unzip and run ``ImageResizer.exe``),
  for computers where installing software is not allowed

The installer is not code-signed, so Windows SmartScreen may show a warning
("More info" → "Run anyway").

Logo
----

The logo is generated by ``tools/make_logo.py`` in the app colors:

.. code-block:: console

    python tools/make_logo.py preview.png src/ImageResizer/resources

Project layout
--------------

- ``src/ImageResizer/core.py``: image processing, no UI (fully tested)
- ``src/ImageResizer/app.py``: the Toga user interface
- ``src/ImageResizer/presets.py``: preset sizes
- ``src/ImageResizer/theme.py``: colors, spacing and shared styles
- ``src/ImageResizer/settings.py``: saved settings
- ``src/ImageResizer/i18n.py``: translations (add a language here)
- ``src/ImageResizer/dnd.py``: Windows drag and drop
